## Project Title

Data Analyzer and Transformer Program

## Project Description

This is a simple Python program used to analyze and transform a list of
numbers. It allows the user to enter data, view basic information,
calculate factorial, filter data, sort data, and display dataset
statistics.

## Features

-   Input data
-   Display data summary
-   Calculate factorial using recursion
-   Filter data using lambda function
-   Sort data in ascending or descending order
-   Display dataset statistics
-   Exit the program

## Technology Used

-   Python

## How to Run

1.  Install Python.
2.  Open the project in VS Code.
3.  Run the Python file.
4.  Select an option from the main menu.
5.  Enter the required data.
